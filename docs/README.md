## About this project

This is a **concept/demo** website built from a real restaurant's public Google listing. It is not the restaurant's official site, and the restaurant is not affiliated with it. Dish pictures are original SVG illustrations, not photos of the real dishes, and the restaurant's own photo is deliberately not stored in this repository.
